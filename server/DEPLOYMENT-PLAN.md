# План размещения на собственном сервере

Зафиксировано 30 октября 2026 года.

- Новый сайт планируется разместить на собственном сервере и заменить им действующий сайт gss.ru.
- Доступа к серверу пока нет; его операционная система и конфигурация неизвестны. Настройка и перенос отложены до получения доступа. Пока продолжается редактирование сайта.
- Обсуждалась рекомендация Linux + Nginx + PHP-FPM; окончательная конфигурация не выбрана.
- Сайт статический, база данных не требуется. Node.js 24 нужен для сборки, постоянно работающий процесс Node.js не требуется.
- Форма заявок подготовлена для PHP 8.2+ с OpenSSL, Mbstring и Sessions. SMTP-параметры пока неизвестны. Реальная отправка на info@gss.ru не активирована.
- Комплект для переноса создаётся командой `npm run build:hosting`: `_hosting/public` — публичные файлы, `_hosting/gss-private` — приватные настройки и зависимости вне публичного каталога.
- До переезда нужны домен/настройка DNS, HTTPS, SMTP-доступ, разрешённые исходящие подключения к SMTP и резервное копирование. Пароли не хранить в Git.
- Предложено сначала проверить сайт и доставку заявок на test.gss.ru, затем переключить основной домен. Этот этап ещё не выполнялся.
- Схему автоматической доставки сайта и обновления новостей на собственном сервере нужно выбрать после получения доступа; обсуждался GitHub Actions с загрузкой по SSH.
- Текущая публикация через GitHub Pages сохраняется до отдельного решения о переносе. Обработчик PHP на GitHub Pages не работает.

Инструкция по форме и SMTP: [README.md](README.md).
