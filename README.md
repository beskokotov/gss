# Гарант-Сервис Самара

Региональный сайт на React и Vite: система ГАРАНТ, решения по профессиям, услуги, полезные материалы, вопросы и ответы, контакты.

## Просмотр без Node.js

Скачайте архив репозитория, распакуйте его и откройте `preview.html` двойным щелчком. В этот файл встроены JavaScript, стили, изображения и шрифты. Node.js и локальный сервер для просмотра не нужны.

## Разработка и запуск исходников

Нужен Node.js 24 или новее.

```sh
npm ci
npm run dev
```

Сервер выведет адрес, обычно http://localhost:5173.

Все изображения, логотипы и шрифты включены в репозиторий в `public/assets`. Дополнительные загрузки для просмотра сайта не нужны. Команда `npm run assets` при необходимости заново скачает оригинальные логотипы и шрифт из указанных источников.

```sh
npm test
npm run build
npm run preview
```

Обновить автономный файл после изменения исходников: `npm run build:preview`.

`dist/` содержит готовую статическую сборку. Ее нужно отдавать через HTTP; для открытия двойным щелчком используйте автономный `preview.html`, а не исходный `index.html`.

## Наполнение

- `src/content.js`: контакты, решения по профессиям, услуги, материалы, вопросы и ответы.
- `src/App.jsx`: компоненты страницы и интерактивное поведение.
- `src/styles.css`: стили и адаптивные правила.
- `src/Icon.jsx`: локальные SVG-иконки.
- `public/assets/`: оба оригинальных логотипа, локальный Manrope и две созданные иллюстрации WebP.

Форма готовит письмо в почтовой программе посетителя. Она не отправляет заявку автоматически. Телефоны и почта работают как прямые ссылки. Отправку через сервер можно добавить отдельно после определения API и утверждения документов об обработке данных.

## Проверка

Восемь тестов Vitest прошли. Проверены якоря, мобильное меню, клавиатурные вкладки, подготовка и кодирование письма, закрытие диалога и возврат фокуса, управление анимацией и отказ доступа к буферу обмена. Сборка Vite прошла. HTML, JavaScript, CSS, логотипы, шрифты и иллюстрации доступны по HTTP с кодом 200.

CSS содержит правила для настольных экранов, планшетов и телефонов, а также `prefers-reduced-motion`. Визуальное тестирование в реальном браузере в текущей среде недоступно; проверки DOM не подтверждают отсутствие визуальных дефектов.
